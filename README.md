# Mathematical and Numerical Methods for Radiative Transfer in the Atmosphere — Code Companion
## Introduction
Atmospheric temperature is part of a very complex system, modelled by the equations of meteorology for short-term predictions and by climatology for long-term statistical estimations. The 3 fundamental blocks of meteorology are the equations for fluids for the atmosphere, the Navier-Stokes or shallow water equations for the oceans and the radiative transfer equations (RTE) for sunlight and infrared radiations from Earth. The book deals with this third block.
