# CHAPTER 7
## Mathematical Results on the VRTE

This chapter has only one numerical section: existence and regularity of the solution of

$$
{\mathcal L} u := \mu\partial_z u + \partial_z\log n (1-\mu^2)\partial_\mu u + \kappa(z) u  = f, ~~in ~\Omega
~~
u|_\Sigma=u_\Sigma
$$

applied to

$$
{\mathcal L}([\tilde I,\tilde Q]^T) = S \hbox{ in }\Omega, \quad \tilde I|_\Sigma=I_\Sigma,\quad \tilde Q|_\Sigma=0
 $$
 
  with 
 
 $$
 \Omega=(-1,1)\times(0,Z),
 $$
 
 $$
 \Sigma=\left([0,1]\times\{0\}\right)\cup\left([-1,0]\times(\{Z\}\right).
 $$

Existence being based on Friedrichs system theory it is appropriate to use Discontinuous Galerkin (DG) FEM.

The FreeFem++ script 

- DGgreygradedindex.edp
- DGgreygradedindex.md

does just that, applied to the system (I,Q) with the usual boundary conditions.

- DGtransportSolver.py

is entirely generated by Anthropy's Claude.ai from the latex above and the request to generate a DG solver in Python. It runs for a scalar equation with $f=0$ and $I_\Sigma=(\mu^+,0)$. Its companion program

- validate_against_exact_solution.py

is a test with a comparison with a manufactured solution obtained by changing the values of $I_\Sigma$.
